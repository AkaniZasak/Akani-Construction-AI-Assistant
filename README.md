# Akani Construction AI Assistant

## CAPACITI AI Skills Acceleration Project

**Developer:** Akani Success Kubayi

**Live Website:** https://akanizasak.github.io/Akani-Construction-AI-Assistant/

## Project Overview

Akani Construction AI Assistant is a web-based workplace productivity application designed to support civil engineering and construction-related administrative tasks. It demonstrates how structured digital tools and AI-inspired workflows can improve productivity, organisation and communication.

## Project Objectives

- Improve workplace communication and productivity.
- Support construction task planning and organisation.
- Assist with preparing meeting summaries and action items.
- Help users structure civil engineering research requests.
- Demonstrate digital development and prompt engineering skills.

## Main Features

### 1. Email Assistant
Helps users prepare professional email drafts for construction-related communication.

### 2. Meeting Summariser
Organises meeting notes into structured summaries and action items.

### 3. Task Planner
Generates structured construction task plan drafts from user input.

### 4. Research Assistant
Helps prepare research prompts for civil engineering and construction topics.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub and GitHub Pages
- ChatGPT for development guidance and prompt planning

## How to Use

1. Open the live website.
2. Select one of the four productivity tools.
3. Enter your request or notes.
4. Click Generate Draft.
5. Review and edit the generated result before using it.

## Current Limitations

This version uses predefined JavaScript-based templates to generate structured drafts. It is not connected to a live AI language model or external research service. Outputs require user review, especially for technical construction tasks.

## Future Improvements

- Integrate a secure AI service for more flexible responses.
- Improve the user interface and mobile accessibility.
- Add export options for generated documents.
- Introduce additional construction-specific productivity tools.

## Responsible AI and Safety

Users should verify all generated content, protect confidential information and avoid treating draft construction plans as approved technical instructions. Engineering calculations and safety-critical work must be checked by appropriately qualified professionals.
